# ИИ — План поставок

Отдельный Streamlit-проект. Формирует Excel с матрицей рекомендованных количеств по Т1–Т40.

## Что хранится где
- **GitHub**: код, CatBoost `.cbm`, подтверждённые постоянные правила `rules/supply_rules.json`, история коммитов.
- **PostgreSQL**: исходная история меню и реализации; приложение только читает данные.
- **Streamlit Secrets**: строка подключения PostgreSQL и GitHub fine-grained token. Никогда не добавляйте действительные секреты в GitHub.

## Запуск
1. Загрузите файлы в отдельный GitHub репозиторий.
2. Создайте приложение Streamlit Cloud, entrypoint `app.py`.
3. Добавьте секреты по образцу `.streamlit/secrets.toml.example`.
4. `github_repo` задайте в виде `OWNER/REPO`, GitHub token — fine-grained, с доступом **Contents: Read and write** только к этому репозиторию. Используется для записи правил по подтверждению.
5. Откройте приложение, выберите дату меню и нажмите «Сформировать план ИИ».

## Ограничения версии 0.1
- Используется существующая экспериментальная модель CatBoost, без автоматического переобучения.
- Ограничение изменения относительно фактического плана: настраиваемые +/-10–50%.
- Время распродажи, достоверные остатки, цветовые пороги и ограничения спроса не внедрены.
- Команда вида «Т1 не ест кашу» сохраняется как подтверждённое структурированное правило через форму.
- Корректировки Excel не обучают модель и не сохраняются.
- Нет записи в рабочий план меню; Excel требует проверки перед использованием.

## Важно
В `engine.py` используются таблицы `planning.menu_plan` и исходная модель `catboost_first_model.cbm`. Их структура должна совпадать с действующей рабочей средой. Файл `rules/supply_rules.json` должен существовать в репозитории.
